# ☕ Coffee Sales Dashboard Project

**Project Title:** Coffee Sales Dashboard Project  
**Platform:** Maven Analytics  
**Tool Used:** Microsoft Excel, Pivot Tables, Pivot Charts  

---

## 🎯 Objectives

- Track total revenue and transaction patterns across different timeframes and store locations  
- Identify high-performing product categories and optimize product offerings  
- Analyze customer purchasing behavior by day, time, and location  
- Provide store managers and stakeholders with actionable insights for operational decisions  

---

## 📂 Data Source

This dataset was provided by Maven Analytics as part of an Excel dashboard challenge.  
It contains detailed transaction-level data from a fictional coffee shop chain.

**Key fields include:**

- `transaction_id`: Unique ID for each transaction  
- `transaction_date`: Date of transaction (MM/DD/YY)  
- `transaction_time`: Time of transaction (HH:MM:SS)  
- `transaction_qty`: Quantity of items sold  
- `store_id`: Unique store identifier  
- `store_location`: Store location name  
- `product_id`: Unique product ID  
- `unit_price`: Retail price of each item  
- `product_category`: Main category (e.g., Beverage, Food)  
- `product_type`: Type (e.g., Espresso, Pastry)  
- `product_detail`: Detailed product name or description  

---

## 📈 Key Features & Pivot Tables

- **KPI Cards:** Total Revenue, Total Transactions
- **Pivot Table: Total Revenue by Month** – Trend analysis to identify seasonal patterns  
- **Pivot Table: Transactions by Day of Week** – Understand weekly customer behavior  
- **Pivot Table: Transactions by Hour of Day** – Identify peak business hours  
- **Pivot Table: Transactions by Product Category** – Highlight best- and worst-performing product lines  
- **Pivot Table: Total Revenue Comparison by Location** – Compare store performance across locations  

---

## 🎛️ Interactive Filters

- **Select Location** – Filter the dashboard to analyze individual store performance  
- **Select Month** – Drill down into specific monthly performance data  

---

## 📌 Deliverables

- Excel dashboard with fully interactive PivotTables, PivotCharts, and slicers  
- Structured and clean data tables optimized for efficient analysis  
- Professionally designed layout for readability and ease of use

## 🪄 Recommended Analysis Questions

- How have total sales and revenue changed over time at Maven Roasters?  
- Which days and hours are the busiest across locations?
